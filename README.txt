FATMI BIRTHDAY WEBSITE
======================

HOW TO PREVIEW
--------------
Open index.html in a browser.

HOW TO CUSTOMIZE
----------------
Almost all text/content lives in content.js.

PHOTOS
------
1. Put your photos/screenshots inside the "assets" folder.
2. Edit content.js.
3. Change a gallery photo "src" from:
   src: ""
   to:
   src: "assets/your-photo.jpg"

MUSIC
-----
Paste a Spotify / Apple Music / YouTube link into:
music.link

FINAL PRESENT
-------------
Paste your final gift link into:
gift.link

HOSTING
-------
This is a static website, so it can be hosted free on:
- GitHub Pages
- Netlify
- Vercel

No backend or coding setup is required.
